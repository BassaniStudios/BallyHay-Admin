      Restore de banco

      cuidado

      Envia um arquivo .db para restaurar a economia local. Com Turso ativo o bot pode recusar restore por arquivo — use o fluxo no Discord nesse caso.

      Boas práticas

      • Faça backup antes de qualquer restore.
      • Em Turso remoto, prefira o comando de restore no Discord.
      • Wake não altera dados — só “acorda” / confirma o serviço.
      • Backup manual depende de BACKUP_CHANNEL_ID e do cog Backup carregado.

      Como o BallyHay funciona

      Bot privado (convite manual), multi-servidor, focado apenas em economia tema GTA Roleplay. Dentro de cada servidor ele publica painéis embeds com botões para jogadores e staff.

      1. Painéis no Discord

      Staff usa comandos /gtarp panel e /gtarp adm1…adm5 para postar painéis permanentes nos canais. Os jogadores interagem pelos botões dos embeds.

      2. Economia por servidor

      Wallet, inventário, XP, ranks, daily, jobs, imposto semanal e cooldowns são isolados por guild (multi-tenant).

      3. Staff role

      Por servidor você define um cargo (Role ID) que pode usar comandos administrativos da economy. Configure neste painel em Servidores → Gerenciar.

      4. Backup e dados

      Backup automático/manual para canal Discord. Storage local SQLite ou remoto Turso. Restore por arquivo só quando não há Turso ativo.
